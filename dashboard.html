🗺️ How It Works — Plain English Tour

1. Frozen rulebook. Three strategies (EMA-200, Divergence, MBV) plus all settings are locked into config.py. The lock = a hash code (6ce4b38242d54771). If anyone changes a rule, the hash changes and all previous results expire.
2. Test on history. The engine replays 15 years of US, UAE, and crypto data, simulating real trades with real costs (commissions, spreads, slippage). It splits history into a "training" half it ignores and an "out-of-sample" half it scores against.
3. Two gates judge. The per-ticker gate asks "does this single stock have edge?" The portfolio gate asks "does this whole strategy have edge across the market?" Both must pass strict thresholds. Failed tests are kept (no cherry-picking) and the haircut penalty grows with each test tried.
4. Live signal watcher. Strategies that cleared the portfolio gate get a Python detector that runs every 2 hours. It checks if today's bar triggered an entry or exit on the watched tickers (DY, EXPGY, PSX, ARW, ROL).
5. Phone alerts. When a signal fires, Telegram pings Ahmed (@AIV_Fund_Bot) with the entry/exit price. The first 10 real signals get compared against backtest expectations.
6. Every action is logged. Every test run writes to audit_trail.md with the config hash. An outside reviewer (Cowork) can re-run the same hash and get the same verdict — that's the audit guarantee.
